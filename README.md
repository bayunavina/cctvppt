# KAI PENGADAAN

Presentasi interaktif pengadaan CCTV KAI untuk Jawa dan Sumatera.

**Situs:** https://bayunavina.github.io/cctvppt/

- 342 lokasi pengadaan: 313 Jawa dan 29 Sumatera.
- 45 kelompok alokasi: J01–J37 dan S01–S08.
- Data tabel, skema rute, Google Maps, unduhan rute Google Earth/KML, serta hasil pengujian.
- Koordinat menunjukkan stasiun, bukan titik pemasangan kamera hasil survei. Garis rute bersifat skematis.

## Publikasi

`site.zip` memuat situs statis beserta CSV, JSON, KML, lisensi font, dan PDF sumber terverifikasi. Workflow `.github/workflows/kai-pengadaan-pages.yml` membuka paket, menyiapkan artefak, lalu menerbitkannya melalui GitHub Pages.

Perbarui `site.zip` pada cabang `main` untuk menerbitkan versi baru. Riwayat perubahan kode kelompok dan audit alokasi tersedia di halaman Pengujian.
